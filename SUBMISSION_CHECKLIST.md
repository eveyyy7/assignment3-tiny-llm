# Before submission

- Read README.md and make sure you can explain the actual results in your own words.
- Keep both executed notebooks and the four complete evaluation result sets.
- Include corpus/ teaching files, evals/ fixed tests, helper code, saved models and evidence/ screenshots.
- The main reported chat evidence uses the starter model; verification/ is a separate reproducibility check.
- Create one public GitHub repository and upload this folder’s contents, with README.md at the repository root.
- Open the repository signed out; check notebook outputs, plots, screenshots and evidence links.
- Submit the public repository URL through the course portal: https://submissions-portal-eight.vercel.app/
- Original backups are retained locally outside this upload folder. No retraining is required for this package.
